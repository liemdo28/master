# Phase 5F Runbook

List actions:

`npm run personal-os -- actions list`

Show action detail:

`npm run personal-os -- actions show <id>`

Approve:

`npm run personal-os -- actions approve <id>`

Execute an approved action:

`npm run personal-os -- actions execute <id>`

Reject:

`npm run personal-os -- actions reject <id>`

Routine validation:

`npm run test:controlled-actions`

`npm run test:controlled-actions-security`

`npm run test:controlled-actions-restart`

`npm run test:controlled-actions-evaluation`

`npm run phase5f:acceptance`
