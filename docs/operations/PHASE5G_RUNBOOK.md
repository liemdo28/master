# Phase 5G Runbook

## Status

```powershell
npm run personal-os -- governance status
```

## Policies

```powershell
npm run personal-os -- governance policies
```

## Budgets

```powershell
npm run personal-os -- governance budgets
```

## Anomalies

```powershell
npm run personal-os -- governance anomalies
```

## Emergency Lockdown

```powershell
npm run personal-os -- actions lockdown
```

Unlock requires an explicit local command:

```powershell
npm run personal-os -- actions unlock <killSwitchId>
```

No remote automatic unlock exists.
