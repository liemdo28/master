## What TABC Covers

The Texas Alcoholic Beverage Commission (TABC) license is required for any establishment selling alcohol. Required fields:

| Field | Description |
|---|---|
| Title | TABC License — [Store Name] |
| Store | B1, B2, or B3 |
| Category | licensing |
| Frequency | Annual |
| Due Date | [NEEDS CEO INPUT — expiration date] |
| Owner | Store Manager |
| Checker | CEO |
| Approver | CEO |
| Escalation | If not renewed 30 days before expiration |
| Evidence | Updated TABC certificate PDF |
| SLA | Must be renewed before expiration date |
